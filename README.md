## 📖 Tentang Repositori

Repositori **Javascript-11A** ini dikelola sebagai wadah dokumentasi seluruh progres belajar, latihan kode (_coding exercises_), dan tugas-tugas praktikum Pemrograman JavaScript di bawah bimbingan guru pengampu di **SMKIT Ibnul Qayyim Makassar**[cite: 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8].
